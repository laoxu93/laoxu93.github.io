博客搭起来了。

用的是 Hexo，源码放在 GitHub 上，每次往 `main` 分支推代码，GitHub Actions 会自动跑 `hexo generate`，把生成的静态页面发布到 GitHub Pages。写完一篇文章，提交、推送，剩下的就不用管了。

<!-- more -->

## 打算写点什么

暂时没定太死的主题，大概是这几类：

- 折腾过程里踩到的坑，以及最后是怎么绕出去的
- 一些工具的用法笔记，主要写给以后的自己看
- 偶尔的随笔

## 怎么新建一篇文章

```bash
npx hexo new "文章标题"
```

会在 `source/_posts/` 下生成一个 Markdown 文件，写完之后本地预览：

```bash
npm run server
```

确认没问题就提交推送，等 Actions 跑完，线上就更新了。

先这样，慢慢写。
